# Five Minute Mirror

사용을 줄이고 싶은 앱을 열기 전에 5분 동안 자기 자신과 머무는 시간을 만드는 Android 앱입니다.

## 현재 구현: Phase 1

- Android / Kotlin / Jetpack Compose
- 전면 카메라 미리보기
- 거울 형태의 셀카 화면
- ML Kit 온디바이스 얼굴 감지
- 얼굴이 화면 안에 있을 때만 5분 타이머 진행
- 얼굴이 사라지면 타이머 일시정지
- 5분 완료 화면
- 카메라 영상 저장/업로드 없음

## 다음 단계

1. 설치된 앱 목록 표시
2. 사용을 줄이고 싶은 앱 선택
3. 선택 앱 실행 감지
4. 5분 거울 완료 후 원래 앱 사용 허용
5. 앱 이탈/전화/화면 잠금에 대한 세션 규칙
6. 긴급 해제

## 개발 환경

Android Studio에서 프로젝트를 열고 Gradle Sync 후 실제 Android 기기에서 실행하세요.

카메라 및 얼굴 감지는 실제 기기 테스트를 권장합니다.

## 제품 원칙

> 사용하지 마세요가 아니라, 5분 후에도 사용하고 싶다면 사용하세요.

카메라 프레임에 얼굴이 존재하는지만 판단하며 신원을 식별하지 않습니다.
